## 1. 目标

把任务创建与执行改造为「**方案配置页 + 任务详情页流水线**」的两段式体验：

1. **方案页面**：配置内容来源（三种模式之一）+ 四类模型配置 → 一键创建任务
2. **任务详情页**：进入 S1-S6 六步流水线，每步**可查看、可编辑、可重新生成**，逐步推进到出片

---

## 2. 三种模式（方案页入口）

| 模式 | 输入 | S1 文案来源 |
|---|---|---|
| ① 直接使用方案 | 文案标题（**留空则系统从文案内容提取**）+ 文案内容 | 直接用填的文案 |
| ② AI 二创 | 文案标题（留空则提取）+ **二创原文案内容** + **二创提示词** | 用二创提示词重新生成文案 |
| ③ AI 创业 | **商品库选品**（/app/products 一件商品）+ **二创提示词** | 用二创提示词对商品生成文案 |

### 2.1 方案页配置项（三模式统一）

**内容来源区**（按模式切换）：
- ① 直接使用：标题（可选）+ 文案内容（必填）
- ② AI 二创：标题（可选）+ 原文案内容（必填）+ 二创提示词（必填）
- ③ AI 创业：商品选择器（单选一件商品）+ 二创提示词（必填）

**模型配置区**（四类，下拉选择，默认值来自模型配置中心 /app/models）：
1. **分镜提示词模型**（LLM，如 deepseek）
2. **图片提示词模型**（LLM/生图）
3. **配音渠道**（参考 MoneyPrinterTurbo 音频设置：音色 / 语速 / 音量 / 字幕开关）
4. **视频模型**（i2v 视频生成，走现有 i2v 渠道如 Kling；ffmpeg 静态合成仅作兜底/可选）

提交 → 创建任务 → 跳转任务详情页。

## 3. 任务详情页流水线（S1-S6）

| 步骤 | 内容 | 操作 |
|---|---|---|
| **S1 文案** | 按模式得到文案：① 直接用填的 / ② 二创生成 / ③ 商品生成 | **可编辑、可重新生成**（重新生成调 LLM） |
| **S2 分镜** | 调**分镜提示词**（**下拉框可选，预置 2-3 套系统默认**：通用解说 / 带货种草 / 故事叙事，有默认值）拆分文案 → 多组镜头 | 每组镜头含：**标题 / 内容 / 字幕 / 图片提示词 / 图片比例**；镜头可增删改 |
| **S3 生图** | 用 S2 的图片提示词逐镜生图 | **生成后可编辑、可重新生成**（单张/批量） |
| **S4 配音** | 用 S2 内容配音 | 可配置**字幕**（开关 / 字号 / 位置）；音色 / 语速 / 音量来自方案页配音渠道 |
| **S5 复核** | 汇总检查（文案 / 镜头 / 图 / 音频 / 字幕） | 通过后进入 S6；不过则回到对应步骤修改 |
| **S6 生成视频** | 图片 + 配音 + 字幕合成，**以 i2v 视频生成为主**（现有 i2v 渠道，如 Kling I2V） | **材料可编辑**（合成前可改任意材料，生成后可重新生成） |

### 3.1 S2 分镜核心规格（本次改造重点）

**输出必须是结构化镜头组**，每镜头为：

```json
{
  "index": 1,             // 镜头编号（镜头1、镜头2…）
  "title": "镜头标题",
  "content": "内容",       // 该镜可读文案句，摘自原文，NOT 提示词
  "subtitle": "字幕文本",   // 可短于配音
  "image_prompt": "…",     // 图片提示词，英文，单独字段
  "aspect": "9:16"         // 图片比例：9:16 / 16:9 / 1:1
}
```

**红线**：
- 「内容」是给用户看/配音的可读文案句，「图片提示词」是生图专用英文提示词，**两者必须分离，严禁混作一坨提示词**
- 分镜提示词下拉框：预置 2-3 套系统默认（通用解说 / 带货种草 / 故事叙事），有默认选中值
- 镜头数量：6-12 个可调

## 4. 验收标准

1. 三种模式都能从方案页创建任务并进入 S1-S6
2. ① 标题留空 → 系统从文案内容提取（校验：生成任务标题非空）
3. S2 分镜提示词下拉可选（默认选中「通用解说」），拆出的镜头**每镜含 标题/内容/字幕/图片提示词/比例**，镜头可增删改
4. S1/S3 可重新生成且结果可编辑（S3 重新生成后图片可单张替换）
5. S4 配音可配置字幕（开关 / 字号 / 位置）；S6 **i2v 视频生成出片**（ffmpeg 静态合成为兜底）
6. S5 复核状态流转正确
7. 原有功能不回归（项目库 / 商品库 / 模板 / 素材 / 模型配置页正常）
