## 已知限制/未覆盖
- **i2v 模式**：wingray 无 i2v 通道，L5 对 static 跳过；i2v 任务创建预期 403 I2V_NOT_AVAILABLE（未在真实档复测，静态代码路径已验证）
- **Creem 真实支付跳转**：CREEM_API_KEY 未配置正式值，checkout 跳转用测试环境验证（503 未配置路径）；正式上线前需配 Creem 正式 key + price_id
- **OAuth Google**：无正式 client id，走 500 OAUTH_NOT_CONFIGURED 降级（P2 验证）
- **邮件发送**：dev 模式 magic-link 打印日志，生产需配 SMTP
- **前端浏览器自动化**：按用户要求未启动 headless Chrome，页面验证用 build + HTTP 内容抽查 + API 层覆盖
