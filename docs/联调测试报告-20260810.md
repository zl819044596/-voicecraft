## 三、测试中发现并修复的问题（3 个）

### 3.1 【严重】重新运行流水线丢失任务配置
- **现象**：`POST /api/projects/:id/run` 创建新任务时 config 从空重建，只保留前端传的 synthesis/run_mode → 任务详情页保存的**自定义提示词（prompts）丢失**、模型配置被重置、i2v 项目重跑变 static。
- **修复**（commit `9a20542`）：run 端点先继承该项目最近任务的 config（含 prompts/models/synthesis/aspect），再用请求体覆盖。
- **验证**：i2v 项目 run 后 synthesis 正确保留为 i2v，10 步跑通。

### 3.2 【中等】快速生成创建任务时半自动模式丢失
- **现象**：创建端点 `buildQuickGenConfig` 将 run_mode 固定为 auto，快速生成页选择的"半自动"不生效。
- **修复**（commit `9a20542`）：创建时读取请求中的 run_mode。
- **验证**：auto_run + run_mode=semi 创建的任务每步 waiting 正常。

### 3.3 【低】资产下载类型不匹配
- **现象**：S4 生成的图片资产表类型为 `shot`（单数），下载端点白名单只有 `shots`（复数）→ 用资产表类型请求会 400。前端实际用 `shots` 路径（正常），属数据模型命名不一致。
- **修复**（commit `9a20542`）：下载端点增加 `shot` 别名兼容。
- **验证**：`/assets/shots/shot-01.png` 与 `/assets/shot/…` 均可下载。

> 另：排查过程中确认"i2v 任务卡在字幕步骤"的根因（render 结果映射静态化）已于上轮修复（commit `b986c3a`），本轮 2 轮 i2v 均未再复现。
