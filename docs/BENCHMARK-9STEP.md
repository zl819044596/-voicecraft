## 一、9 步工作流总览（竞品形态）

```
1. 商品信息解析（可选：不使用商品）
2. 分段拆解 / 文案准备
3. 文案二创生成（原文 → 二创，合规结果：已通过）
4. 文案定稿
5. 分镜拆解（每个场景产出 3 输出：口播文本 / 字幕文本 / 生图提示词）
6. 画面提示词生成
7. 素材生成（生图，每张可改：保存并仅重绘当前镜头）
8. 配音字幕生成（音色/速度/BGM/字幕约束）
9. 剪映草稿生成（导出）
```

## 二、每步关键交互（从截图提取）

### Step 3 文案二创生成
- 左：原文（底本）展示（1,353 字面板）
- 右：当前文章编辑器（标题 + 正文生成结果）
- 「回到底本修改」按钮（改原文 → 重跑二创）
- 合规结果：已通过（内嵌合规检查）
- 顶部 meta：9/16 成片 · 不使用商品 · 89% 完成（进度/模式/完成度）

### Step 5 分镜拆解
- 镜头列表（8 个场景：逆境看曹操 / 赤壁惨败 …）
- **每个镜头生成 3 个输出**：口播文本 / 字幕文本 / 生图提示词（同屏三栏）
- 输出比例 9:16，「所有比例一致」提示
- 每镜头操作：「保存镜头」「重新生成本镜头提示词」（单镜重生成）

### Step 7 素材生成
- 生图提示词列表（每条状态：已定稿）
- 右侧当前镜头预览图 + 完整提示词 + 输出比例
- 「保存并仅重绘当前镜头」（局部重生成，不动其他镜头）
- 模式：半自动（顶部显式标注）
- 「回退本步修改」（回退到本步编辑，不丢下游）

### Step 8 配音字幕生成
- BGM 选择（不使用 BGM / 可上传）
- 音频风格（Vivi 2.0 等音色）、速度 1x
- **字幕约束可配**：每行最多字数（9）/ 每段条数（12）/ 总条数（16）
- 字幕段列表（每条源文本 + 音色）可改
- 「回退本步修改」

### Step 9 剪映草稿生成
- 产出剪映草稿格式（draft 文件），供剪映直接导入

## 三、对齐到我们的核心功能（映射）

| 竞品 9 步 | 我们的核心功能（CORE-FEATURES）| 关键设计点 |
|----------|------------------------------|-----------|
| 1 商品信息解析 | ③ 商品生成文案 | 商品 → 解析 → 文案（可不选商品）|
| 2 分段拆解 | 拆分（拆分规则可配）| 拆分结果即镜头列表 |

| 5 分镜拆解 | 拆分产物细化 | **每镜头 3 输出：口播/字幕/生图提示词**（单镜重生成）|
| 6 画面提示词 | 生成规则（图片）| 画面提示词可改 |
| 7 素材生成 | 生成图片（每张可改）| 保存并仅重绘当前镜头；半自动模式 |
| 8 配音字幕 | 语音（每条可改）| 音色/速度/BGM/字幕约束可配 |
| 9 剪映草稿 | 合成视频 + 下载 | 成片 + 剪映草稿导出（每环节 zip）|

## 四、必须吸收的设计要素（实现时强制）

1. **步骤化显式工作流**：9 步全览（左栏步骤 + 当前步主面板），非黑盒自动流水线
2. **每步可回退**：「回退本步修改」（改本步不丢下游，重跑下游）
3. **局部重生成**：「保存并仅重绘当前镜头」（单镜头级 regenerate，不触发全量）
4. **每镜头三输出同屏**：口播文本 + 字幕文本 + 生图提示词（分镜拆解产物结构）
5. **字幕约束可配**：每行字数 / 每段条数 / 总条数
6. **合规内嵌**：文案生成后合规检查结果（已通过）
7. **模式显式**：半自动 / 全自动标注
8. **剪映草稿导出**：最终交付含剪映草稿格式
9. **比例一致**：所有镜头输出比例统一（9:16）
10. **进度 meta**：顶部显示 成片数/总数 · 商品使用 · 完成百分比
