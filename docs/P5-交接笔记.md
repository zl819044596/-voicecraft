## 2. Creem 签名方案修正（重要，覆盖任务书说法）

任务书/03 接口文档写 "HMAC-SHA256 时间戳方案"——**错误**。按 Creem 官方文档（docs.creem.io/code/webhooks、api-reference/introduction）：

- 签名头：**`creem-signature`**（不是 X-… 前缀）
- 算法：**HMAC-SHA256(webhook_secret, rawBody)**——raw body 直接作消息，**无时间戳、无拼接**
- 比对：constant-time（crypto.timingSafeEqual）
- Express 必须用 **raw body**（官方 SDK 提示：`express.raw({ type:'application/json' })`），不能用 express.json() 再 JSON.stringify
- **官方事件名与任务书不符**：官方为 `checkout.completed`（一次性完成）、`subscription.active` / `subscription.paid` / `subscription.canceled` / `subscription.scheduled_cancel` / `subscription.past_due`；博客文另提 `payment.succeeded` / `refund.created`。任务书的 "order.completed / payment.succeeded" 不是官方事件名 → 处理器应按官方事件名分发（一次性→checkout.completed，订阅→subscription.*），并对未知事件宽容（ack 不炸）
- 幂等：`orders.creem_order_id` UNIQUE，重复投递 ON CONFLICT 跳过
- 密钥：CREEM_API_KEY（x-api-key 头，商户 API）/ CREEM_WEBHOOK_SECRET 从 env 读；缺失时 billing 端点 503 BILLING_NOT_CONFIGURED、webhook 503，应用照常启动（对齐 GOOGLE 缺失时的 OAUTH_NOT_CONFIGURED 模式，index.js line 435-438 注释）
- 金额单位：Creem 价格为 **cents**（官方 skill 注明 1000=$10.00）；合同锚定 1 积分=$0.01
