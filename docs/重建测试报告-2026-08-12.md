## 3. 流水线引擎（L1–L10 + L1.5）

- **static 自动档全链路**：9 步（跳过 L5），steps 1–4、6–10 全部 done，`current_step=9`；L8 compose 由 render worker 产出 `final.mp4`；L10 生成 export zip。
- **复核门（review gate）**：finalizeStep 在 L8 合成前暂停 `pause_kind='review_gate'`、`pause_resume_step=8`；`POST /continue` 记录 `review_passed=true` 后 L8 继续执行。
- **semi 模式**：每步后暂停 `pause_kind='semi'`，逐步 continue 走通。
- **i2v**：环境内 wingray 无 i2v 通道，托管档优雅降级 `403 I2V_NOT_AVAILABLE`（真实通道需生产 key，代码路径已就绪）。
- **免费重跑**：`/auth/me` 返回 `free_reruns_per_task`（按套餐档位），计费重跑走积分。

## 4. 积分与账本（C11 商业规则）

- static 成片 **冻结 60 → 结算 6 → 自动退 54**；trial 120 → 结算后 114。账本 `credit_ledger` 落账、`balance_after` 连续。
- `credit_ledger_task_once` 部分唯一索引保证任务结算幂等。

## 5. Key 池（RPM 令牌桶 + 熔断器）

`/tmp/kptest.mjs` 对 live DB+Redis **7/7 通过**：
pick-newest（closed 优先 + 最新优先）→ RPM 耗尽故障切换 → 5 次失败熔断 open → 跳过 open 故障切换 → cooldown 后 half_open 探测 → 成功回 closed。
托管档默认模型由 providers/runtime 按类兜底（`LLM_MODEL` / `IMAGE_MODEL` / `TTS_MODEL` / `I2V_MODEL`）。

## 6. 渲染 worker

- BLPOP `avs:render`，job 分发 `srt` / `compose` / `compose-i2v`，完成推 `avs:render:done`，成功静默、仅错误打日志。
- 静态任务 L8 合成产物经 ffmpeg 产出 `final.mp4` 并上传 MinIO `avs-assets/<project>/<task>/`。

## 7. 导出契约

- `GET /export/:id` 以 `exports.id` 定位；越权 403、过期 410（30 天 TTL）、响应头 `X-Export-Expires-At` / SHA256 与 DB `zip_hash` 一致；zip 含成片 + 字幕 + 工程 JSON + LICENSE。
- 已验证：zip 可解压、成片可播放、SHA256 匹配 DB。

## 8. GDPR（C6/R8）

- `GET /account/export`：zip 含 manifest/profile/prompts/products/benchmarks/media_assets/orders/subscriptions/credit_ledger/projects；24h 限流；**不含 credentials 密文与 api_cost_log**。
- `DELETE /account`：邮箱确认 → active 订阅 409 → 在跑托管任务退款解冻 + 置 cancelled → PII 墓碑（tombstone email、google_sub 清空）→ 删凭据/素材/资料库/积分账户 → projects 级联 → 订单/账本/成本流水留匿名化存根。

## 10. 发现并修复的 Bug（5 项，全部现场复测通过）

1. **keypool `loadPoolRows`** 查询了 credentials 不存在的 `c.model, c.voice` 列（04 §2.2 无此列）→ `column does not exist`。改为不选该列，返回 `model/voice: null`，由 providers/runtime 按类兜底默认模型。
2. **credentials 路由** 携带 `provider_class`（credentials 表无此列，04 §2.2）。按 04 §4 重写：GET `?provider=` 过滤、DELETE `?id=`、`409 DUPLICATE_CREDENTIAL` / `409 CREDENTIAL_IN_USE`。
3. **account 注销** `UPDATE tasks SET ... error='account deleted'` 但 tasks 无 error 列（04 §2.6）→ 500。移除 error 列赋值，仅置终态。
4. **append-only 触发器** 拦截 FK 驱动的清理（credit_ledger `ON DELETE SET NULL` 置 `task_id`、api_cost_log `ON DELETE CASCADE`）→ `55000`。`block_append_only_mutation()` 增加对「FK 级联清理」的豁免（仅财务行内容变更仍拦截）。
5. **models 页 `ensureCredential`** 操作顺序不合规。按文档重排：PUT model-config `credential_id:null` 解绑 → DELETE 旧 credential（`?id=`）→ POST 新 credential（label 释放）；POST body 去掉 `provider_class`；孤儿凭据清理改 `?id=`。

## 14. 导航对齐 — 移除冗余「模板中心」

**用户反馈**：左侧导航的「提示词中心」与「模板中心」是两个入口，但二者实为同一功能。

**确认**：参考原型 `app.html` 侧边栏共 **11 项**，Config 组只有「模型配置 Models + 提示词中心 Prompts」，**无模板中心**。模板/分镜预设能力在原型中不占顶层入口——分镜预设（general/ecommerce/story 等）直接在向导内以 chips 选择；提示词模板则在提示词中心浏览/编辑。

**修改**：
- `src/components/app/layout/Sidebar.tsx`：Config 组移除 `{ href: "/app/templates", labelKey: "nav.templates" }`，恢复为模型配置 + 提示词中心两项，侧边栏回到 11 项，与原型逐项一致。
- `src/i18n/{en,zh}.json`：删除 `nav.templates` 键。

**验证**（Playwright + session cookie，经 nginx https）：`https://127.0.0.1/app` 侧边栏 11 项，含「Prompts 提示词中心」，无任何 Templates 链接。

**遗留**：`/app/templates` 页面文件（`src/app/app/templates/page.tsx`）按权限约定未删除，现为孤儿路由——无导航入口，仅可直接访问 URL。该页是提示词中心的只读浏览视图（每条链「编辑到提示词中心」）。如需彻底移除，手动删除该文件及其 i18n `templates.*` 键段即可。
